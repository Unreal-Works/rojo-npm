# rojo-npm

A Node.js wrapper for Rojo that allows you to install and use Rojo through NPM.

You should prefer [rkkit](https://github.com/evilbocchi/rkkit) if you would rather use Rokit in NPM.

## Installation

```bash
npm install -g rojo
```

Or install locally in your project:

```bash
npm install rojo
```

## Usage

If installed globally, you can use Rojo commands directly:

```bash
rojo init
rojo serve
rojo build
```

If installed locally, you can use it through npx:

```bash
npx rojo init
npx rojo serve
npx rojo build
```
